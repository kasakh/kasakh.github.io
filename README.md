# Siva Rajesh Kasa

Source for [kasakh.github.io](https://kasakh.github.io), built with [Quarto](https://quarto.org/).

## Local preview

Install Quarto, then run:

```bash
quarto preview
```

The preview server binds to the local machine. Quarto renders the production site into `docs/`:

```bash
quarto render
```

## Content

The main pages are `index.qmd`, `research.qmd`, `publications.qmd`, `writing.qmd`, and `about.qmd`. Mathematical notes live under `writing/` and support TeX equations through MathJax. Add verified paper, code, and project page links directly beside each publication in `publications.qmd`.

The older notebooks and the 2018 summer school site remain in the repository as an archive.
